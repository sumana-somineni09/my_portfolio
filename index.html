Personal project · Deployed

Evidence-Based Claim Verification

Problem

I first built this as a classic fake-news classifier: TF-IDF over 72,000 articles, five models, >95% accuracy. Then I looked closer at what it had learned. It wasn't detecting falsehood — it was detecting writing style. The benchmark was flattering me. So I rebuilt it.

What I built

A six-stage pipeline that decomposes text into atomic factual claims, retrieves supporting and refuting evidence from fact-check databases and the open web, and returns verdicts with citations. Natural-language-inference stance classification distinguishes topically adjacent evidence from claim-relevant evidence. Prompt-hash disk caching and difficulty-based model routing (Llama 3.3 70B for reasoning, 3.1 8B for classification) cut API consumption ~60%, keeping ~40 LLM calls per document inside a free tier.

0.46 four-way verdict accuracy on a stratified AVeriTeC sample vs. a 0.30 majority-class baseline (n=37). Lower than the classifier it replaced — and the number I trust.
